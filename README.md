**Versión 1.1 (problemas resueltos y laboratorios)**

Curso abierto para aprender a **analizar problemas, diseñar soluciones algorítmicas y evaluar su eficiencia** antes de depender de un lenguaje de programación específico.

La ruta comienza con pensamiento algorítmico y representaciones como pseudocódigo y diagramas de flujo, y conecta esos conceptos con implementaciones prácticas en Python, Java y JavaScript.

## Practicar con casos completos

Explora los [25 laboratorios](laboratorios/README.md), prepara [el entorno](docs/ENTORNO.md) y consulta [las verificaciones realizadas](docs/VERIFICACION.md). Cada unidad enlaza contrato, traza, programa, resultado esperado y soluciones razonadas.

## Objetivo

Al finalizar el curso podrás:

- descomponer problemas en pasos solucionables;
- identificar entradas, procesos y salidas;
- representar algoritmos mediante pseudocódigo y diagramas;
- realizar pruebas de escritorio;
- utilizar decisiones, ciclos y estructuras de datos;
- modularizar soluciones;
- aplicar algoritmos de búsqueda y ordenamiento;
- comprender recursividad;
- analizar de forma introductoria la eficiencia temporal y espacial;
- reconocer estrategias de resolución de problemas;
- implementar una misma solución en diferentes lenguajes;
- justificar por qué una solución es adecuada para un problema.

## Metodología

Cada unidad seguirá, cuando corresponda, esta secuencia:

1. Comprender el problema.
2. Identificar entradas, procesos, restricciones y salidas.
3. Diseñar la solución.
4. Representarla con pseudocódigo o diagramas.
5. Realizar una prueba de escritorio.
6. Implementarla.
7. Probar casos normales, límites y errores.
8. Analizar alternativas.
9. Resolver ejercicios.
10. Completar un reto.

## Lenguajes

El curso no dependerá de un único lenguaje.

Los fundamentos se estudiarán primero de forma algorítmica y, cuando aporte valor, se mostrarán implementaciones equivalentes en:

- Python.
- Java.
- JavaScript.

El objetivo es comprender la **solución** antes que memorizar sintaxis.

## Principio del curso

> Primero entiende el problema. Después diseña la solución. Al final escribe el código.
