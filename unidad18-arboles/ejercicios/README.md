# Ejercicios — Árboles

1. Identifica raíz, hojas, profundidad y altura.
2. Preorden, inorden y postorden.
3. Inserta valores en BST.
4. Busca valores.
5. Encuentra mínimo/máximo conceptual.
6. Compara árbol equilibrado y degenerado.

## Reto
Modela una jerarquía de categorías y diseña recorridos para mostrarla completa y localizar una categoría.
