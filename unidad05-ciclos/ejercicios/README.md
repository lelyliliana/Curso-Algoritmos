# Banco de ejercicios — Unidad 05

## Recorridos conocidos
1. Mostrar 1..N.
2. Mostrar N..1.
3. Sumar 1..N.
4. Tabla de multiplicar.
5. Factorial.

## Contadores y acumuladores
6. Promedio de N valores.
7. Contar positivos, negativos y ceros.
8. Sumar solamente pares.
9. Encontrar máximo y mínimo sin ordenar.

## Cantidad desconocida
10. Leer hasta centinela.
11. Validar una entrada hasta que sea correcta.
12. Procesar ventas hasta indicar fin.

## Trazado
Para cada algoritmo construye una tabla con:
- iteración;
- dato;
- contador;
- acumulador;
- estado relevante.

## Reto
Procesa una secuencia de notas hasta un centinela y calcula cantidad, promedio, aprobadas, reprobadas, mayor y menor. Define qué ocurre con cero datos.
