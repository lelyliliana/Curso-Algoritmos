# Unidad 20 — Divide y vencerás

## Propósito
Resolver problemas dividiéndolos en subproblemas más pequeños, resolviéndolos y combinando resultados.

```text
DIVIDIR
  ↓
RESOLVER
  ↓
COMBINAR
```

Ya has visto ejemplos relacionados:
- búsqueda binaria;
- Merge Sort;
- Quick Sort.

## Preguntas de diseño
1. ¿Cómo divido el problema?
2. ¿Los subproblemas son similares al original?
3. ¿Cuándo dejo de dividir?
4. ¿Cómo combino las respuestas?

## Ejercicios
1. Explica búsqueda binaria como divide y vencerás.
2. Traza Merge Sort indicando división y combinación.
3. Diseña máximo de un arreglo dividiéndolo en mitades.
4. Compara con una solución secuencial.

## Reto
Elige un problema que pueda dividirse en partes y diseña una solución recursiva de divide y vencerás. Justifica caso base y combinación.
