# Banco de ejercicios — Unidad 01

## Nivel 1 — Identificar
Para cada situación determina entrada, proceso y salida.

1. Convertir pesos colombianos a dólares usando una tasa dada.
2. Calcular edad aproximada a partir del año de nacimiento.
3. Calcular consumo promedio de combustible.
4. Calcular porcentaje de asistencia.

## Nivel 2 — Analizar
Para cada problema agrega restricciones y casos límite.

1. Dividir una cuenta entre varias personas.
2. Calcular velocidad promedio.
3. Determinar cuánto material se necesita para cubrir un área.
4. Calcular cambio después de una compra.

## Nivel 3 — Descomponer
Divide en subproblemas:

1. Sistema de préstamo de libros.
2. Registro de ventas diarias.
3. Control de asistencia.
4. Sistema básico de parqueadero.

## Nivel 4 — Justificar
Elige uno de los problemas anteriores y explica:
- qué información es indispensable;
- qué información sería irrelevante;
- qué supuestos hiciste;
- qué podría hacer fallar tu solución.
