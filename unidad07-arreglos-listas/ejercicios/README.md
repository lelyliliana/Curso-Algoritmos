# Ejercicios — Arreglos y listas
1. Suma, promedio, máximo y mínimo.
2. Primera y última aparición.
3. Todas las posiciones de un valor.
4. Segundo mayor sin ordenar.
5. Eliminar duplicados conservando orden.
6. Rotar una lista una posición.
7. Comparar dos listas posición a posición.
8. Separar positivos y negativos.

## Reto
Analiza 30 mediciones: estadísticas, valores fuera de rango y secuencia más larga por encima del promedio.
