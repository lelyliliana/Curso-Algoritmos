# Ejercicios — Pilas y colas

## Pilas
1. Simula push/pop.
2. Invierte una secuencia.
3. Valida (), [] y {} balanceados.
4. Evalúa conceptualmente una secuencia de deshacer.

## Colas
5. Simula turnos.
6. Procesa tareas en orden de llegada.
7. Modela una cola con prioridades como problema de extensión.

## Reto
Diseña un sistema de atención donde lleguen y salgan personas. Registra estado de la cola después de cada evento y calcula espera conceptual.
