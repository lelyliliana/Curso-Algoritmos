# Unidad 17 — Listas, conjuntos y mapas

## Propósito
Elegir estructuras según las operaciones que necesita el problema.

## Lista
Conserva una secuencia de elementos y normalmente permite repetidos.

## Conjunto
Modela pertenencia y evita duplicados.

## Mapa
Relaciona claves con valores.

```text
"ana" → 4
"luis" → 7
```

## Pregunta correcta
No preguntes “¿cuál estructura es mejor?”. Pregunta:
- ¿necesito orden?
- ¿permito duplicados?
- ¿busco por posición o clave?
- ¿necesito contar frecuencias?

## Patrón: frecuencias
```text
PARA CADA palabra EN palabras
  frecuencia[palabra] ← frecuencia[palabra] + 1
FIN PARA
```

## Ejercicios
1. Eliminar duplicados.
2. Intersección de dos conjuntos.
3. Contar palabras.
4. Agenda nombre→teléfono.
5. Agrupar elementos por categoría.

## Reto
Procesa una lista de transacciones y genera totales por categoría usando una estructura clave→valor. Justifica por qué un mapa es adecuado.
