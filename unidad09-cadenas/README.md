# Unidad 09 — Cadenas y procesamiento de texto

## Propósito
Tratar el texto como información que también puede recorrerse, analizarse y transformarse.

## Operaciones
- longitud;
- acceso a caracteres;
- conversión mayúsculas/minúsculas;
- búsqueda;
- extracción;
- separación;
- reemplazo.

## Patrones algorítmicos
### Contar vocales
Recorrer cada carácter y comprobar si pertenece al conjunto de vocales.

### Palíndromo
Normalizar el texto y comparar posiciones simétricas.

### Frecuencias
Contar cuántas veces aparece cada carácter o palabra.

## Normalización
Antes de comparar texto puede ser necesario:
- convertir a minúsculas;
- retirar espacios;
- decidir cómo tratar tildes y signos.

La regla debe definirse, no asumirse.

## Ejercicios
1. Contar vocales.
2. Contar palabras.
3. Invertir una cadena.
4. Detectar palíndromo.
5. Encontrar carácter más frecuente.

## Reto — Analizador de texto
Recibe un texto y calcula número de caracteres, palabras, vocales, frecuencia de palabras y palabra más larga. Documenta cómo normalizas el texto.
