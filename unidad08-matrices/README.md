# Unidad 08 — Matrices y datos bidimensionales

## Propósito
Representar información organizada en filas y columnas.

Una matriz puede modelar notas por estudiante y asignatura, ventas por sucursal y mes o un tablero de juego.

```text
[ 4  7  2 ]
[ 9  1  5 ]
[ 3  8  6 ]
```

## Recorrido
Se requieren normalmente dos ciclos: uno para filas y otro para columnas.

```text
PARA fila ...
  PARA columna ...
    PROCESAR matriz[fila][columna]
  FIN PARA
FIN PARA
```

## Operaciones
- suma total;
- suma por fila;
- suma por columna;
- búsqueda;
- diagonal principal;
- transposición introductoria.

## Ejercicios
1. Sumar todos los elementos.
2. Promedio por fila.
3. Mayor de cada columna.
4. Suma de diagonal.
5. Buscar coordenadas de un valor.

## Reto — Registro de notas
Modela notas de varios estudiantes en varias actividades. Calcula promedio por estudiante, promedio por actividad y estudiante con mayor promedio.
