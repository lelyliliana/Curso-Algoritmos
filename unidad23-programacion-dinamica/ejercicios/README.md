# Ejercicios — Programación dinámica

1. Fibonacci memoizado.
2. Fibonacci tabulado.
3. Escalones.
4. Suma mínima en cuadrícula.
5. Identifica estado y transición.
6. Compara llamadas con/sin memoización.

## Reto
Toma un problema recursivo con subproblemas repetidos, define estado, recurrencia, casos base y construye versiones memoizada y tabulada.
