# Unidad 24 — Taller de resolución de problemas

## Propósito
Elegir estrategias sin que el enunciado indique qué algoritmo utilizar.

## Método de trabajo
Para cada problema entrega:

1. reformulación del problema;
2. entradas y salidas;
3. restricciones;
4. ejemplos;
5. casos límite;
6. estrategia candidata;
7. pseudocódigo;
8. prueba;
9. análisis de eficiencia;
10. implementación cuando corresponda;
11. explicación de alternativas descartadas.

## Problemas propuestos
### 1. Duplicados
Detectar si una colección contiene elementos repetidos.

### 2. Dos valores
Encontrar dos números que sumen un objetivo.

### 3. Intervalos
Seleccionar la mayor cantidad de actividades compatibles.

### 4. Camino
Determinar si existe conexión entre dos nodos de una red.

### 5. Frecuencias
Encontrar los elementos más frecuentes de un texto.

### 6. Orden y búsqueda
Decidir si conviene ordenar antes de realizar múltiples búsquedas.

### 7. Cambio
Analizar cuándo una estrategia greedy funciona o falla.

### 8. Laberinto
Encontrar una ruta válida respetando obstáculos.

## Regla
No se evalúa solamente obtener una respuesta. Debes poder justificar la estrategia.
