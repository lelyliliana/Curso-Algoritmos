El programa de cada unidad prepara datos y muestra resultados; algoritmos.py contiene las funciones reales que debes estudiar. No confundas el wrapper de impresión con el algoritmo. Las pruebas comparan con sorted, enumeración de subconjuntos/combinaciones y criterios verificables, no solo con otra copia de la misma implementación.
