# Unidad 11 — Algoritmos de ordenamiento básicos

## Propósito
Comprender cómo diferentes estrategias transforman una colección desordenada en una secuencia ordenada.

## Bubble Sort
Compara elementos vecinos e intercambia cuando están en orden incorrecto.

## Selection Sort
Busca el menor elemento restante y lo coloca en su posición.

## Insertion Sort
Construye progresivamente una parte ordenada insertando cada nuevo elemento en el lugar adecuado.

## No memorices el código
Para cada algoritmo responde:
1. ¿Qué parte ya está ordenada?
2. ¿Qué compara?
3. ¿Cuándo intercambia o desplaza?
4. ¿Cuántas pasadas necesita?
5. ¿Qué ocurre con datos ya ordenados?

## Ejemplo para trazar
```text
[5, 2, 4, 1]
```
Registra el arreglo después de cada pasada.

## Comparación experimental
Cuenta:
- comparaciones;
- intercambios o movimientos;
- tiempo para distintos tamaños.

## Ejercicios
Traza manualmente Bubble, Selection e Insertion con:
1. [4,3,2,1]
2. [1,2,3,4]
3. [3,1,4,2]
4. datos repetidos.

## Reto
Implementa o representa los tres algoritmos, genera varias entradas y argumenta cuál se comporta mejor en cada caso observado.
