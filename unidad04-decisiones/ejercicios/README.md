# Banco de ejercicios — Unidad 04

## Nivel 1
1. Par o impar.
2. Positivo, negativo o cero.
3. Mayor de dos valores.
4. Puede votar según una edad mínima dada.

## Nivel 2
5. Mayor de tres valores contemplando empates.
6. Clasificar nota por rangos.
7. Validar triángulo a partir de tres lados.
8. Calcular tarifa según consumo por tramos.

## Casos límite
Diseña pruebas para:
- edad exactamente 18;
- nota exactamente 3.0;
- saldo exactamente 0;
- valores iguales.

## Depuración
Analiza por qué el orden de estas condiciones puede producir errores:
```text
SI nota >= 3
  "Aprobado"
SINO SI nota >= 4.5
  "Excelente"
```

## Reto
Construye una tabla de decisión para una tarifa con al menos dos variables antes de escribir el pseudocódigo.
