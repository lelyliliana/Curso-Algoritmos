# Unidad 21 — Algoritmos voraces (Greedy)

## Propósito
Comprender estrategias que construyen una solución tomando en cada paso una decisión local.

Una estrategia greedy:
1. tiene candidatos;
2. selecciona una opción según un criterio;
3. conserva decisiones sin retroceder;
4. espera alcanzar una solución global adecuada.

## Advertencia
Elegir lo mejor “ahora” **no garantiza** siempre la mejor solución final.

## Ejemplo conceptual: selección de actividades
Elegir actividades compatibles terminando primero puede producir una solución óptima bajo el modelo clásico.

## Contraejemplos
El cambio de monedas greedy funciona para algunos sistemas monetarios y falla para otros. Debes justificar la propiedad del problema, no asumirla.

## Ejercicios
1. Selección de actividades.
2. Diseña un criterio greedy para cambio.
3. Encuentra un sistema de monedas donde falle.
4. Compara greedy con exploración completa en un caso pequeño.

## Reto
Propón una estrategia greedy para un problema de planificación, prueba varios casos y busca deliberadamente un contraejemplo.
