# Ejercicios — Greedy

1. Selección de actividades.
2. Cambio con sistema convencional.
3. Busca contraejemplos de cambio.
4. Selección de elementos bajo una regla local.
5. Distingue decisión local de objetivo global.

## Reto
Propón un algoritmo greedy, intenta demostrarlo con casos y después intenta romperlo deliberadamente con un contraejemplo.
