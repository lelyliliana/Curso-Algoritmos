1. área de triángulo;

```text

```

Luego crea tu propia secuencia de cinco asignaciones e intercámbiala con otra persona para resolverla.

## Depuración

```text
INICIO
  total ← precio * cantidad
  LEER precio
  LEER cantidad

```
