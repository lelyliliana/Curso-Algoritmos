# Banco de ejercicios — Unidad 06

## Funciones pequeñas
Crea funciones para:
1. esPar;
2. maximo;
3. convertirTemperatura;
4. calcularArea;
5. validarRango.

## Composición
Diseña un algoritmo principal que use funciones independientes para:
- leer/recibir datos;
- validar;
- calcular;
- clasificar;
- presentar resultado.

## Diseño
Decide cuáles deberían retornar un valor:
- mostrar menú;
- calcular promedio;
- validar contraseña;
- convertir moneda;
- imprimir reporte.

Justifica.

## Pruebas
Para cada función define:
- caso normal;
- caso límite;
- caso inválido cuando aplique.

## Reto
Diseña una pequeña biblioteca de funciones matemáticas y de validación. El programa principal debe poder leerse como una secuencia de acciones de alto nivel.
